# 都市闲趣玩法与活力系统

> 采集日期：2026-09-27 ｜ 来源：公开攻略站与社区（非官方）
> ⚠️ **本页信源冲突最严重**，各站对"哪个玩法最赚"排序不一致，请务必阅读「信源冲突」一节。

## 都市活力（City Stamina）

- **用途**：**仅**用于「都市闲趣」小游戏玩法（入口：都市 → 都市闲趣）
- **恢复**：**每周一凌晨 5:00 整点回满**（周内不用完即浪费）
- **上限**：随都市大亨等级提升
- **补充**：可使用「活力补充」类道具（Refresh Recharge，每个恢复 100 点）
- **与副本体力不同**，见 [stamina-systems.md](./stamina-systems.md)

### 关键倍率

> 都市大亨 **Lv 16** 后，都市闲趣方斯加成 **+100%**（由约 500 → 1000/点）。
> **冲都市大亨等级 = 冲收益倍率**，优先级很高。

### 玩法细节

**都市送货（City Delivery）**
- 开货车按导航送达，完成请求可提升「**异常家具**」等级
- 异常家具等级 → 提高**每周**方斯收入
- **因此前期建议优先刷到满级**，而不只是当刷钱手段
- 哈索尔 5 级可解锁额外同城派送次数
- ⚠️ 车技不好易出车祸**扣钱**；修车行修过一次车可解锁家具「修车工」，随时储存万能机油

**雨燕出行（网约车）**
- 接单 → 导航 → 送达；自动寻路或手动驾驶皆可
- 练车技 + 熟悉地图；结果看顾客性格（有运气成分）

**海角钓手（钓鱼）**
- 到水域挂机开钓，**可全自动**
- **都市活力为空时也能钓鱼存储**（重要：不浪费离线时间）
- 提升钓鱼等级可领环石与「涂鸦进行中」时装（Esper Zero 外观）

**赛道竞速**
- 耗活力参赛；**首通与挑战奖励含环石**
- 完整通关需顶级车辆

**其他娱乐**
- 麻将（Little Sparrow）：升级羁绊后可挂机刷方斯；「麻雀球」可换麻将皮肤与特效；日麻（Ver 1.2 加入）耗活力更多
- 格斗（Fight Club）：输也拿奖，可 AFK；「强效止痛药」可在专属商店换物品
- 俄罗斯方块 / 超音速：纯方斯产出
