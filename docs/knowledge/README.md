## 项目背景

本仓库是《异环》玩家辅助工具的 Web 前端。开发此类工具时，**游戏数据的准确性与时效性是最大风险**，因此：

1. 所有游戏数值必须标注来源与采集日期
2. 信源冲突时不擅自统一，并列标注差异
3. 无可靠信源的数据不写（宁缺毋滥）

## 主要玩法板块

| 板块 | 说明 |
|------|------|
| 都市闲趣 | 耗**都市活力**的小游戏集合，产方斯（基础比例 1 活力 = 1000 方斯，每周一 05:00 回满） |
| 一咖舍（开店经营） | 咖啡厅 / 古董店，不耗活力，被动收益；**收益累计上限 72 小时** |
| 大亨计划激励金（原粉爪银行·大劫案） | 限时「搜打撤」玩法，大额方斯来源；1.3 版后额度与排球之星周常联赛、即刻落槌共享 |
| 店长特供 / 店长特工 | 战斗关卡，高效刷方斯 |
| 异象地带 | 耗**角色像素（副本体力）**，产养成材料 |
| 都市大亨 | 等级系统，决定各项解锁与收益倍率 |
