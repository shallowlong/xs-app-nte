## 维护规则

1. 新增数据必须记录**来源 URL + 采集日期**
2. 发现信源冲突 → 记入本文件「冲突记录」节，**不擅自取平均值或选一个**
3. 任何数值被证实过期 → 直接修正对应文档，并在本文件记录修正历史
4. 官方公告 > 专门攻略站 > 综合攻略站 > 营销号（信源可信度降序）
